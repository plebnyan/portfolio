How to install
Gmail: Settings (gear) → See all settings → General → Signature → Create new. Select the signature in the box above, copy, paste into the field, Save changes.

Apple Mail: Mail → Settings → Signatures. Create one, then paste. (Uncheck "Always match my default message font" so the formatting sticks.)

Outlook: Settings → Mail → Compose and reply → Signatures → paste into the box → Save.
